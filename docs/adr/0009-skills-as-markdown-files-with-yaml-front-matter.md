# ADR-009: Skills as Markdown files with YAML front matter

- **Status:** Accepted
- **Date:** 2026-11-05
- **Deciders:** @nitesh

## Decision

Skills as Markdown files with YAML front matter.

## Alternatives considered

JSON, database rows.

## Rationale and trade-offs

Human-readable, easy to share and diff. Trade-off: needs schema validation
