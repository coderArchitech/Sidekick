# ADR-007: Capture exclusion via OS APIs, with visible status and fallback (auto-hide, second device)

- **Status:** Accepted
- **Date:** 2026-11-05
- **Deciders:** @nitesh

## Decision

Capture exclusion via OS APIs, with visible status and fallback (auto-hide, second device).

## Alternatives considered

No exclusion.

## Rationale and trade-offs

Keeps private notes off shared screens. Trade-off: depends on OS and capture method; can't be fully guaranteed
