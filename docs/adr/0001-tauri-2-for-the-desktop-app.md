# ADR-001: Tauri 2 for the desktop app

- **Status:** Accepted
- **Date:** 2026-11-05
- **Deciders:** @nitesh

## Decision

Tauri 2 for the desktop app.

## Alternatives considered

Electron.

## Rationale and trade-offs

Smaller installer and much lower RAM/CPU for an always-running app. Trade-off: Rust learning curve; Playwright can't drive the full app
